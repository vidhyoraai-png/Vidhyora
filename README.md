## FLUX image generation

The project currently uses separate generation and editing credentials in
`settings.py`, as requested by the project owner. In the AI model picker,
choose **FLUX.2 Klein 4B**. A text prompt creates a new image. NVIDIA's hosted
endpoint currently accepts only its preset `example_id` references for editing;
editing arbitrary uploaded images requires a self-hosted FLUX NIM or another
image-editing API endpoint.
